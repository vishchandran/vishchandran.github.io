## Publication

GitHub Pages serves the repository root on `main`; `.nojekyll` enables direct static-file serving. A push to `main` can publish the site. This local proposal must be reviewed and explicitly approved by the owner before pushing, merging or deploying.

## Validation

Check all internal anchors, outbound links, desktop/mobile layouts, keyboard navigation, the mobile menu and the expandable integration detail. Verify the distinction between professional delivery, independent software and conceptual exercises before publication. There is no build or lint task configured in the original repository; use static markup and JavaScript validation plus browser review.
